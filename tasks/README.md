# 任务看板 · 协作协议

> 本目录是仓库的**共享任务看板**：主 Agent 把「思想」拆成可落地的任务发布到
> `TASKS.md`，其他 AI 领取后完成，完成后把任务条目删除。
>
> 它和 `AGENTS.md` 分工不同、互不冲突：**AGENTS.md 管「谁有权限做什么」**，
> **本看板管「当前有哪些活、谁在做、做完了没有」**。

---

## 一、任务有哪几种状态

| 状态 | 含义 |
|---|---|
| `open` | 待认领。任务已发布，等任何 AI 来领。 |
| `in-progress` | 进行中。已被某 AI 认领，**其他人不得再动这个任务**。 |
| `blocked` | 阻塞。认领后发现卡点（缺依赖、等别人、信息不足），写明原因后挂起，**不删除**。 |

## 二、任务的生命周期

```
发布 open ──> 认领 in-progress ──> 完成（删除条目）
                     │
                     └──> 阻塞 blocked ──> 解除后回到 open / in-progress
```

### 1. 发布（主 Agent 做）
把「思想」拆成一个个独立可验收的任务，每个任务写入 `TASKS.md` 的「待认领」区，
状态 `open`、认领者留空。**只发「需要跨会话、需要别人接」的活**；自己当场能做完的
不必上板。然后单独 commit（`chore(tasks): 发布任务 xxx`）。

### 2. 领取（任何 AI 做）
开工前**先 `git pull` 拉最新，再读一遍 `TASKS.md`**。认领时：
- 把该任务状态从 `open` 改成 `in-progress`，在「认领者」栏写上自己（会话角色名）；
- **先单独 commit 这次认领**（`chore(tasks): 认领 T-xxx`），再开始写代码。

这样能防止两个 AI 同时领同一个任务互相撞车。

### 3. 完成（任何 AI 做）
验收标准全部勾选、跑通 AGENTS.md 第 6 节自检后：
- **把该任务的整个条目从 `TASKS.md` 删除**；
- commit（按 Conventional Commits，`feat`/`fix`/`docs` 等，见 AGENTS.md 第 3 节）。

### 4. 阻塞（任何 AI 做）
卡住时把状态改成 `blocked`，在条目里写清「卡在哪、需要谁/什么才能继续」，
commit 后**保留条目，不删除**。解除后改回 `open` 或 `in-progress`。

## 三、任务条目格式

每个任务在 `TASKS.md` 里是一个三级标题区块，字段固定、缺一不可：

```markdown
### T-001 一句话标题
- **状态**: open
- **认领者**: （留空 = 待认领）
- **优先级**: P1
- **创建**: 2026-10-18
- **目标**: 一句话说清要交付什么。
- **验收标准**:
  - [ ] 明确可勾选的验收点 1
  - [ ] 明确可勾选的验收点 2
- **范围/红线**: 涉及哪些文件/接口；若属 AGENTS.md §0.1「重大修改」，须先提方案。
- **备注**: 背景、依赖、上下文链接等。
```

- **任务 ID** 用 `T-001` 递增，删除后不回收复用（保证历史可追溯）。
- **优先级**：`P0` 紧急 / `P1` 高 / `P2` 普通 / `P3` 低。
- **认领者**：写清楚是哪个会话/角色（如「后端子 Agent」「主 Agent」），避免歧义。

## 四、必须遵守的红线

1. **开工前必读**：先 `git pull`，再读 `TASKS.md`。看不到这条 = 可能领到已被别人
   认领的活。
2. **认领先落笔**：改状态、写认领者，**先 commit 再动手**，不许先写代码后补状态。
3. **完成即删除**：任务条目从看板里整段删掉，不要留着改成「已完成」堆积。
4. **阻塞要写清原因**，不删条目、不假装完成。
5. **一个 commit 只做一件事**：发布/认领/完成各自单独 commit，不和其他代码混在一起。
6. **遵守 AGENTS.md 的推送红线**：只有主 Agent 可 push `master`，其他 AI 走分支 + PR。

## 五、看板只有一个文件

任务统一写在 `TASKS.md`，按三个状态分区排列。改任务 = 编辑 `TASKS.md` 并 commit。
这就是「共享文档」——其他 AI 通过 `git pull` 就能看到当前所有待办与进行中的活。
