# T-001 精简首页中心描述：删除首屏「产品自我介绍」长文案

## 目标

删除首页首屏引导区大标题下方的长描述文案段，让首屏聚焦搜索本身。
这段「输入关键词后，引擎会从视频与图文两条通道并行下探……」属于典型的
AI「描述过多」问题——功能说明不是页面内容，用户不需要被教育引擎怎么工作。

## 验收标准

- [ ] `frontend/src/LingoSeekApp.tsx` 首屏引导区中，大标题下方的长描述 `<p>` 段
      （约 698-701 行）被删除
- [ ] 大标题「一次搜索，看遍视频与图文」保留不变
- [ ] 搜索栏、平台筛选栏、三张特性卡片、热门标签、页脚的视觉与行为均无变化
- [ ] 删除后无布局破损：若间距因删段而失衡，做最小间距修正
- [ ] `cd frontend && npx tsc --noEmit && npm run build` 通过
- [ ] 起服务实跑首屏（:8000 + :5173），确认无布局异常

## 约束条件

- **基本约束**（全局，见 `tasks/README.md` 第五节）：减少不必要的内容生成。
  本任务尤其注意：**删除就是删除，不要用新文案顶替**，不要顺手「优化」其他文案。
- **本任务约束**：
  - 只删长描述 `<p>` 段 + 必要的间距修正；不改组件结构、状态逻辑、样式体系；
  - 三张特性卡片与热门标签**本次不动**（是否精简由使用者后续决定）；
  - 改动预计 < 10 行，禁止顺手重构。
