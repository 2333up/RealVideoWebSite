# T-003 追番前端：追番管理界面 + 进站更新提醒 + 点击跳转

## 目标

在灵搜前端落地追番的完整用户闭环：能管理追番列表、进站时看到更新提醒、
点追番条目自动搜索该番剧并直接看结果。

## 验收标准

- [ ] 追番管理界面：展示追番列表（封面 / 标题 / 最新话数 / 更新状态），支持添加
      （按番剧名搜索、从候选里选择）和删除
- [ ] 顶栏新增追番入口；有更新时入口显示红点
- [ ] 进站时若存在更新番剧 → 顶部横幅提示，点击进入追番列表
- [ ] 点击追番条目 → 自动以该番剧名触发一次搜索，直接展示结果列表
- [ ] `cd frontend && npx tsc --noEmit && npm run build` 通过
- [ ] 实跑首屏（:8000 + :5173）：追番入口、横幅、跳转搜索均正常

## 约束条件

- **基本约束**（全局，见 `tasks/README.md` 第五节）：减少不必要的内容生成——
  UI 文案能短则短，不加没被要求的说明段落、按钮、弹窗。
- **本任务约束**：
  - 复用 `api/client.ts` 的封装风格，追番类型定义与接口调用收进该模块或独立类型文件；
  - 视觉与灵搜现有风格一致（沿用 ink-* 色板、surface 等既有 class），不另立一套主题；
  - 「点击自动搜索」复用现有搜索逻辑/状态，**不要另写一套搜索流程**；
  - 依赖 T-002 后端接口（`/api/anime/*`），联调前先确认后端接口已就绪。
